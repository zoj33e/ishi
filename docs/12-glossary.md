# 12 — Glossary (EN / TH)

Thai terms below are suggestions. Check against Thai Go community usage (Thailand Go Association materials) and record final choices in `13-decisions.md`. Use the same term everywhere (UI, templates, prompts).

| English | Thai (suggested) | Meaning |
|---------|------------------|---------|
| Go | หมากล้อม | The game |
| Stone | หมาก / เม็ดหมาก | A playing piece |
| Intersection / point | จุดตัด | Where stones are placed |
| Liberty | ลมหายใจ | Empty point next to a stone/chain |
| Chain / group | กลุ่มหมาก | Connected stones of one color |
| Capture | กิน | Remove stones with no liberties |
| Atari | อาตาริ (เหลือลมหายใจเดียว) | A group with one liberty left |
| Self-atari | ทำตัวเองให้ติดอาตาริ | Moving into your own atari |
| Suicide (illegal) | ฆ่าตัวตาย (เดินไม่ได้) | Move with no liberties that captures nothing |
| Ko | โคะ | Immediate recapture repetition rule |
| Ko threat | ภัยคุกคามโคะ | Forcing move elsewhere during ko |
| Eye | ตา | Enclosed empty point owned by a group |
| False eye | ตาปลอม | Eye that can be destroyed |
| Two eyes / alive | สองตา / รอด | Group that can't be captured |
| Dead | ตาย | Group that will be captured |
| Ladder | บันได | Zig-zag chase capture |
| Ladder breaker | ตัวทำลายบันได | Stone that breaks a ladder |
| Net | ตาข่าย | Loose capture surrounding |
| Snapback | กินคืน | Sacrifice then recapture more |
| Cut | ตัด | Separating opponent stones |
| Connect | เชื่อม / ต่อ | Joining your stones |
| Capturing race | การแข่งกิน (เซไม) | Two groups racing liberties |
| Vital point | จุดสำคัญ | Key point for life/death |
| Territory | อาณาเขต | Empty area you surround |
| Area scoring | นับพื้นที่ | Stones + territory |
| Komi | โคมิ | Points given to White |
| Pass | ผ่าน | Skip a turn |
| Resign | ยอมแพ้ | Concede |
| Tsumego / life-and-death problem | โจทย์เป็นตาย (ซึเมโกะ) | Tactical puzzle |
| Kyu / Dan | คิว / ดั้ง | Amateur ranks |
| Belt | สาย / เข็มขัด | Ishi's progression level |
| Shape Gym | ยิมรูปหมาก | Ishi's puzzle trainer |
| Capture Go | หมากล้อมกินก่อนชนะ | First-capture-wins mini game |
